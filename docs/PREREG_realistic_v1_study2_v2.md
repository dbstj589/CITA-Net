**작성 시점: 점수 수준 분석 완료 직후, 연구 2의 어떤 학습 런보다 이전.**
v1([`PREREG_realistic_v1_study2.md`](PREREG_realistic_v1_study2.md), 커밋 `ae06ae6`/`32b7550`)을
개정한다. **v1 문서는 이력 보존을 위해 삭제하지 않는다.**

## 0. 개정 사유 — 연구 2 데이터가 아니라 독립 증거에 근거한다

**개정 근거는 연구 2 데이터가 아니다.** 연구 2는 아직 한 런도 돌지 않았다. 근거는 학습을
전혀 쓰지 않은 **점수 수준 분석**(`results/realistic_v1_score_analysis/report_score.md`)이며,
연구 1의 체크포인트만 사용해 얻은 독립 증거다.

### 0.1 `motion` 제외 — 세 분석이 일치하여 무기여

| 분석 | `b_motion` 결과 |
|---|---|
| A 판별력 | 증분 ΔAUC **−0.00035** (test), 한계 AUC **0.4848** (0.5 미만 = 역방향) |
| B 층화 | 예측 반증 0/5, 층간 차이 −0.00027 (무시할 수준) |
| C 추론 시 소거 | ΔF1 **+0.0002**, 부호일관 **2/5**, p=0.713 |

세 분석이 독립적으로 "기여 없음"에 수렴한다. v1이 `motion`을 2위로 올린 근거는 연구 1의
|d| 순위였는데, 그 d는 부록 A에서 밝혀진 **잡음 바닥(영 조작 no_time의 d=−0.554)과 구분되지
않는 크기**였다.

### 0.2 `src` 제외 — 검정 대상과 구성이 불일치

`b_src`는 학습 결과 **범위 [−1.2802, −1.2116], 표준편차 0.0163의 사실상 상수**가 됐다.
상수 오프셋은 쌍 **순위를 바꿀 수 없고**(증분 ΔAUC −0.0024, 한계 AUC 0.5541), 실제로 하는
일은 `p_transition = σ(score)`의 절대 수준을 낮춰 디코더 주의를 날카롭게 유지하는 것이다
(제거 시 평균 p_transition 0.2584 → 0.5135, 예측 매칭 24.9 → 5.6, F1 0.2559 → 0.0714).

즉 `no_src`를 검정하면 **"출처 신뢰도 제약이 정합에 기여하는가"가 아니라 "디코더 주의 온도를
낮추는 상수가 필요한가"를 검정하게 된다.** 구성 타당도가 성립하지 않으므로 확증 실험의
대상에서 제외한다. (온도 역할 자체는 실재하며 별도 연구 주제다 — 본 등록의 범위가 아니다.)

### 0.3 `rel`만 남기는 이유

`b_rel`은 세 분석 모두에서 유일하게 **판별 신호**로 확인됐다:
한계 AUC **0.9030**, 증분 ΔAUC **+0.00453**(5/5 시드 CI가 0 배제), 층화에서 술어조합이 고유한
개체에 이득이 **3.9배** 집중(5/5 예측 확증), 추론 시 소거 ΔF1 **−0.0550**(5/5, p=0.0001).
따라서 **학습 시 F1 기여를 확증할 가치가 있는 유일한 항**이다.

### 0.4 `time`을 위약(placebo)으로 편입

`b_time`은 구조적으로 항상 0이다(블로킹이 전방 시간창만 후보로 내놓으므로 발화 조건 도달
불가; 8,337,448쌍 전수 검증에서 `b_time≠0` 0개). 따라서 `no_time`은 **아무것도 바꾸지 않는
조작**이며, 이 실험의 **위약 팔**로 쓴다. 역할은 아래 §4에서 체제별로 다르다.

## 1. 설계 (사전 고정)

| 항목 | 값 |
|---|---|
| 팔 | `m3_full`(기준선) · `no_rel`(검정) · `no_time`(**위약**) — **3개** |
| 시드 | **19521011 … 19521025 (15개, 지금 고정)** |
| 총 런 수 | 3 × 15 = **45런** |
| 설정 | `configs/realistic_v1/*.yaml` **그대로** (40에폭, num_slots=200, dt=450, floor=300). **수정 금지** |
| 데이터 | `data/realistic_v1` 동일 (재생성 금지) |
| 학습 | `--full-sectors`, GPU. `CITANET_TRAIN_MAX_PAIRS`/`CITANET_EVAL_ON_CPU` 금지 |
| 체크포인트 | best-dev (연구 1과 동일). pair/assign 점수 저장 유지(2차 분석·사후 감사용) |

40에폭 유지 사유는 v1 §3.1과 같다(연구 1·amb160과의 비교 가능성). 따라서 결론에는
**"40에폭 예산 하에서"** 조건이 붙는다.

---

## 2. 1차 가설 (유일)

> **H1**: `no_rel`의 test ΔF1(= `no_rel` − `m3_full`, **동일 시드 짝지음**) < 0

**확증 판정 = 세 조건 전부 충족:**
1. paired t (df=14) **p < 0.05**
2. 부호일관성 **≥ 12/15** (실제 개수를 `x/15`로 그대로 표기)
3. **dev/test 방향 일치**

**단일 사전 등록 가설이므로 다중비교 보정을 적용하지 않는다.** 검정 대상이 하나뿐이고
가설을 사전 고정했으므로 FWER 팽창이 발생하지 않는다. 위약 팔은 가설 검정 대상이 아니라
체제 검증/영분포 추정 장치이므로 보정 계산에 포함하지 않는다(§4).

---

## 3. 분석 계획 (사전 고정)

- **1차 = 표준 디코드.** 주 분석.
- **2차 = revive margin 0.7** (연구 1과 동일 값, **재탐색 금지**).
- 두 분석 모두 **결과 방향과 무관하게 전량 보고**한다.
- recall/precision 채널을 함께 보고한다.
- **v1의 연구 1 풀링 분석(df=19)은 삭제한다.** 실행 체제가 다를 수 있으므로(§4) 통합이
  타당하지 않다. 연구 1과의 대비는 **기술 통계로만** 제시하고 검정하지 않는다.

## 4. 실행 체제 — 스모크 결과에 따라 하나만 채택

45런은 **단일 체제**로 수행한다. 혼합 금지. 기존 연구(frozen/amb160/연구 1)에 **소급 적용
금지**.

### 4.0 체제 판정 규칙 (스모크 실행 전에 고정)

env 게이트 `CITANET_DETERMINISTIC=1` → `torch.use_deterministic_algorithms(True)`,
`cudnn.deterministic=True`, `benchmark=False`, `CUBLAS_WORKSPACE_CONFIG=:4096:8`.
미설정 시 기존 동작 바이트 동일.

검증 3종(각 3에폭, GPU):
- **(a)** 동일 config·동일 시드 2회 → 지표·출력 완전 동일?
- **(b)** `m3_full` vs `no_time` 동일 시드 → 지표·디코드 출력 동일? (시간 항 파라미터 텐서의
  차이만 허용 — weight decay 경로 차이 가능)
- **(c)** 비결정론 대비 감속률

| 스모크 결과 | 채택 |
|---|---|
| (a)·(b) 통과 & 감속 ≤ 40% | **체제 A** (결정론 ON) |
| (a)·(b) 통과 & 감속 > 40% | **정지**, 실측치 보고 후 사용자 결정 대기 |
| (a) 또는 (b) 실패 | **체제 B** (비결정론), 실패 내용 보고 |

### 4.A 체제 A (결정론 ON) — 위약은 **검증 게이트**

같은 시드에서 `no_time`은 위약이므로 ΔF1이 **정확히 0**이어야 한다.
- 각 시드 완료 직후 자동 확인한다.
- **0이 아니면 체제 붕괴로 간주하고 즉시 전체 정지·보고한다.** 사후 합리화 금지.
- 게이트가 유지되는 한, `no_rel`의 ΔF1은 학습 잡음이 제거된 순수 효과로 읽는다.

### 4.B 체제 B (비결정론) — 위약은 **경험적 영분포**

`no_time`의 ΔF1 분포(n=15)가 "아무것도 바꾸지 않은 조작"의 영분포다.
- `no_rel` Δ 분포 vs 위약 Δ 분포의 **짝지은 비교**(동일 시드끼리 차의 차)를 **참고 검정**으로
  병기한다. 이는 §2의 1차 판정을 대체하지 않는다.
- 1차 판정은 §2 그대로 유지한다.

> **유효 절 표시**: 스모크 판정 결과를 여기에 기록한 뒤에만 학습을 시작한다.
> **→ 채택 체제: (스모크 완료 후 기입)**

## 5. 해석 3갈래 (사전 고정 — 결과를 보고 바꾸지 않는다)

| 결과 | 문안 |
|---|---|
| **지지** (§2 세 조건 충족) | "`rel` 항의 **학습 시 F1 기여**를 40에폭·realistic-v1 조건부로 **확립**" |
| **귀무** (충족 실패) | "**판별 신호(점수 수준)는 확립**, 학습 시 F1 기여는 **본 예산·검정력에서 미검출**" — 그대로 보고하며 논문 성립에 영향 없음 |
| **역전** (ΔF1 > 0 방향) | 그대로 보고. 원인 탐색은 **별도 승인** 사항이며 본 연구에서 수행하지 않음 |

귀무 결과가 나와도 점수 수준 분석의 결론(판별 신호 확립)은 독립적으로 성립한다. 두 층위를
분리해 보고하는 것이 이 설계의 요점이다.

## 6. 정지 규칙 (사전 고정)

- **시드 15개에서 정지.** 중간 결과에 따른 증감·조기 종료 금지.
- 중단 사유는 절차 오류뿐: 런 실패(rc≠0), 데이터 오염, slot starvation 재발, 디스크 부족,
  **체제 A의 위약 게이트 위반**.
- 결과 방향은 중단 사유가 아니다. 효과가 소멸해도 그대로 보고한다.
- 사후에 팔·시드·에폭·margin을 추가 탐색하지 않는다.
- **본 보고 이후의 어떤 학습·수리**(b_state 재보정, time 항 수리, 원인 탐색 포함)**도 승인 전
  시작 금지.**
