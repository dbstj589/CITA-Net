# 사전 등록 — 수렴 검증(80에폭): `rel` 효과가 학습 예산의 인공물인가

**작성 시점: 연구 2 v2의 45런이 진행 중이고 그 결과를 보기 이전.** 본 검증의 어떤 런보다 앞선다.
승인: 사용자, 2026-08-05 (유휴 GPU 창 활용).

---

## 1. 왜 필요한가

지금까지의 **모든 결론에 "40에폭 예산 하에서"라는 조건이 붙어 있다.** 근거는 연구 1의 탐색 런이다 —
seed 19521006에서 80에폭이 40에폭보다 test F1이 약 0.05 높았고(m3_full 0.2782 → 0.3312,
no_motion 0.3231 → 0.3752), 80에폭 시점에도 `best_dev_f1`이 여전히 상승 중이었다. 즉 **40에폭은
수렴점이 아니다.**

따라서 연구 2가 `rel` 항의 기여를 지지하든 기각하든, "그 결론이 미수렴 지점에서만 성립하는
것 아닌가"라는 반론이 남는다. 본 검증은 **그 반론 하나만** 겨냥한다.

---

## 2. 설계 (사전 고정)

| 항목 | 값 |
|---|---|
| 팔 | `m3_full` · `no_rel` — **2개** |
| 시드 | **19521011 … 19521020 (10개)** — 연구 2 시드의 앞 10개 |
| 에폭 | **80** (연구 2는 40) |
| 총 런 수 | 2 × 10 = **20런** |
| 실행 체제 | **A (결정론)** — 연구 2와 동일. `CITANET_DETERMINISTIC=1` |
| 설정 | `configs/realistic_v1_conv80/` — 원본 사본에서 **`epochs: 40→80`만** 변경. `configs/realistic_v1/`은 무수정 |
| 데이터 | `data/realistic_v1` 동일 |
| 산출 | `runs/realistic_v1_conv80/` (격리) |

**시드를 연구 2와 공유하는 것이 이 설계의 핵심이다.** 같은 시드·같은 체제(결정론)이므로
40에폭 결과는 연구 2에서 그대로 가져오고, 80에폭만 새로 돌려 **동일 시드끼리 짝지어** 비교한다.
40에폭을 다시 돌리지 않는다.

`no_time`(위약)은 본 검증에 포함하지 않는다. 체제 A에서 위약은 정의상 Δ=0이고 연구 2에서
이미 15시드로 확인되므로 추가 정보가 없다.

---

## 3. 질문과 판정 기준 (사전 고정)

### Q1 (주) — 80에폭에서도 `rel` 효과가 성립하는가

> ΔF1₈₀ = (`no_rel`@80 − `m3_full`@80), 동일 시드 짝지음, test 기준 < 0

**확증 = 세 조건 전부:**
1. paired t (df=9) **p < 0.05**
2. 부호일관성 **≥ 9/10** (이항검정 p = 0.0107; 연구 2의 12/15 = p 0.0176보다 엄격하거나 동등하게 유지)
3. dev/test 방향 일치

### Q2 (부) — 효과 크기가 예산에 의존하는가

> Δ의 차 = ΔF1₈₀ − ΔF1₄₀, 동일 시드 짝지음 (n=10, df=9)

- **차가 0과 구분되지 않음** → 효과는 예산 비의존. "40에폭 하에서" 조건을 **뗄 수 있다**.
- **80에폭에서 축소** → "효과는 미수렴 지점에서 과대추정된다"고 보고.
- **80에폭에서 확대** → "40에폭은 효과를 과소추정한다"고 보고.

### Q3 (기술 통계) — 80에폭은 수렴했는가

절대 F1(40 vs 80)과 `best_dev_f1`의 마지막 구간 기울기를 보고한다. **검정하지 않는다.**
80에폭에서도 상승 중이면 "80에폭 역시 수렴점이 아님"을 명기한다.

**다중비교 보정 없음** — Q1이 유일한 사전 등록 가설이고 Q2·Q3은 기술적 후속이다.

---

## 4. 분석 (사전 고정)

- **1차 = 표준 디코드.**
- **2차 = revive margin 0.7** (재탐색 금지). 결과와 무관하게 병기.
- recall/precision 채널 병기.
- 연구 2(40에폭, n=15)와 본 검증(80에폭, n=10)은 **시드 수가 다르므로 통계 결합하지 않는다.**
  Q2의 짝지은 비교는 **공통 10시드에서만** 수행한다.

---

## 5. 정지 규칙 (사전 고정)

- **시드 10개에서 정지.** 중간 결과에 따른 증감 금지.
- **실패 시 즉시 전체 정지**(사용자 지시, 2026-08-05): 런 실패(rc≠0), 데이터 오염,
  slot starvation, 디스크 부족 중 하나라도 발생하면 로그를 남기고 멈춘다. 건너뛰고 계속하지 않는다.
- 결과 방향은 정지 사유가 아니다. 효과가 소멸해도 그대로 보고한다.
- **본 검증 이후의 어떤 학습도 승인 전 시작 금지.**
