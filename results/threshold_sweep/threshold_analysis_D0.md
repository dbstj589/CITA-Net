## 핵심 질문 (test로 보고, 임계는 dev로 선택)

**(a) 임계를 낮추면 recall/F1이 오르는가?**
- 임계 0.50→0.25: recall 0.524→0.465 (내려간다), F1 0.652→0.603. → 낮출수록 recall은 **내려간다**.
- 임계 0.50→0.90(완화): recall 0.524→0.524, F1 0.652→0.652. → 변화 없음(argmax==null 바닥조건 때문).

**(b) m3_full F1이 no_motion을 따라잡는 임계가 있는가?**
- **따라잡지 못함.** 최고 F1은 임계 0.50의 0.652 (< no_motion 0.703).

**(c) recall을 얻는 대신 잃는 것 (trade-off):**
- 임계 0.25: precision 0.872 (base 0.874), wrong_merge 0.106 (base 0.111), impossible 0.230 (base 0.239).

**(d) F1 최대 임계(dev 기준 선택): 0.50** — dev F1=0.692, 해당 임계 test F1=0.652 (test P=0.874, R=0.524).
